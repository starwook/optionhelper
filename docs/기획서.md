## 1. 배경
토스증권 옵션창은 실시간이지만 아쉬운 점이 세 가지다.
- 콜과 풋을 한 화면에서 못 본다.
- IV, 예상 변동폭, 전략별 손익분기가 안 보인다.
- 토스를 켜 둬야 하는 구조는 포트폴리오용으로 맞지 않는다.

## 2. 화면에서 판단할 것
- 지금 옵션이 비싼가: IV(API값과 직접 역산한 값), IV/HV(20일 실현변동성), IV Rank·퍼센타일(1년 일별 30일 IV 기준, `/iv.html`)
- 프리마켓 갭이 났을 때 개장 직전에 옵션 매도 지정가를 얼마에 걸지: 개장 예상가(`/iv.html`)
- 들고 있는 옵션을 지금 팔지: 세타로 하루 얼마 빠지는지, IV가 1년 평균 수준으로 돌아가면 얼마가 되는지(보유 옵션 시나리오)
- 시장이 몇 % 움직인다고 보는가: 예상 변동폭, 실현 vs 예상
- 어떤 전략이 맞는 구간인가: 롱 스트래들, 롱 스트랭글(±1·±2칸), 숏 풋, 수직 스프레드(데빗·크레딧)의 비용, 손익분기(수수료 반영), 필요한 변동 %, 최대 손익
- 시장 전체 이벤트: 다가오는 FOMC·CPI·PPI·NFP·PCE 일정(ET·KST), 선택한 만기 안에 있으면 경고
- 반도체 특화: 다음 실적발표일(만기가 실적일을 지나면 경고), 과거 실적 다음 날 실제 변동 % vs 이번 옵션의 예상 변동폭, 월별 계절성(평균, 상승 확률)

## 3. 원칙
- 화면의 전략 구간은 **교과서식 참고 지표**이며 투자 조언이 아니다. 화면에 그렇게 표기한다.
- 사양(외부 API)은 추측하지 않는다. `docs/데이터소스-조사.md`에 확인된 것만 근거로 쓴다.
- 데이터가 실시간인지 지연인지 화면에 항상 표시한다.
- 화면에 전문 용어(IV, HV, 그릭스, 전략 이름 등)를 새로 넣을 때는 옆에 `?` 툴팁을 붙이고, 초보자용 1~2문장 설명을 `static/glossary.js`에 추가한다(2026-11-25).
- **IBKR 계좌는 시세 구독에만 쓰고 거기서 옵션(해외 파생상품)을 매매하지 않는다.** 자본시장법 시행령 제184조 제1항상 일반투자자의 해외 파생상품 거래는 국내 투자중개업자(토스)를 통해야 한다. 앱은 IB Gateway의 Read-Only API 설정으로 접속해 주문이 원천적으로 불가능하게 한다.

## 4. 신호 규칙표 (초안, 기준값은 미결)
| 조건 | 해당 구간 |
|---|---|
| IV/HV ≥ 1.3 | 프리미엄 매도형(숏 풋, 크레딧 스프레드)이 유리한 구간 |
| IV/HV ≤ 0.9 | 프리미엄 매수형(롱 스트래들, 롱 스트랭글)이 유리한 구간 |
| 만기 안에 실적발표가 있고 예상 변동폭 < 과거 실적 평균 변동 | 롱 변동성 구간 |
| 만기 안에 실적발표가 있고 예상 변동폭 > 과거 실적 평균 변동 × 1.2 | 실적 프리미엄이 과한 구간(매도형) |

## 5. 단계
0. 데이터 소스 확정 (완료: IBKR + Alpha Vantage)
1. 계산 엔진 + 테스트 (완료)
2. 데이터 연동 + MySQL 스냅샷 기록 (가짜·Alpaca·Alpha Vantage 완료, IBKR은 계좌·TWS API 준비 후)
3. 화면 (완료)
4. 복기 모드 (완료: 저장된 시각을 고르면 그때 체인·전략과 만기 결과를 보여 줌)
5. IV 히스토리 + 보유 옵션 시나리오 (완료: 가짜 데이터로 동작. IBKR 구현체가 `MarketDataSource.dailyImpliedVolatility`를 채우면 실제 값으로 바뀜)

## 미결 사항
- [확인 필요] IBKR 계좌 송금·보유에 외국환거래 신고가 필요한지(GPT 조사 중)
- [확인 필요] 과거 IV·HV·일봉이 무료 주식 시세 구독만으로 조회되는지(계좌 개설 후 실측)
- [확인 필요] Alpha Vantage 실적 캘린더에 장전/장후 구분이 오는지(키 발급 후 실측)
- 개장 예상가 기본값: 주가 변화 행(±3·5%)과 IV 가정 열(−20/−10/+10%p)은 임시값
- [확인 필요] Alpaca 프리마켓(08:00–09:30 ET)에 `prevDailyBar.c`가 전일 종가인지 그 전날 종가인지(실측). 이상하면 화면에서 전일 종가를 직접 입력. 대시보드는 2026-11-24부터 SIP 일봉 마지막 종가를 써서 이 문제를 피한다(개장 예상가 화면은 아직 `prevDailyBar.c`)
- IBKR 계좌 연결 예정 2026-11-25(수)경. 연결 후 `dailyImpliedVolatility`(OPTION_IMPLIED_VOLATILITY 일봉) 구현과 과거 몇 년치까지 받을 수 있는지 실측
- 대시보드의 IV 퍼센타일(지금은 장중 스냅샷 기준)을 IV 히스토리(일별 30일 IV) 기준으로 바꿀지
- 만기 안 FOMC·CPI 등 경제지표를 신호 규칙표에 넣을지(지금은 경고만)
- 경제지표 일정 파일은 2027-12-22까지. 2027년 말에 2028 일정으로 갱신(FOMC 2027-12 회의는 현행 Fed 일정에 없어 미기재)
- 신호 규칙표 기준값(1.3, 0.9, 1.2는 임시값)
- 무위험금리 값(임시 4%)
- 로컬 MySQL DB 이름과 계정(임시: `optionhelper`)
