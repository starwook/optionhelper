# 데이터 소스 조사 (2026-11-20)

GPT 조사 결과를 공식 문서와 포럼으로 다시 확인했다. 확인 수준: **공식** = 해당 회사 문서, **포럼** = 회사 직원 답변, **미확인** = 제3자 자료뿐이거나 못 찾음.

## 1. 옵션 시세

| 소스 | 무료 | 호가 실시간 | IV·그릭스 | 확인 수준 | 비고 |
|---|---|---|---|---|---|
| Alpaca Basic(indicative) | O | **호가는 실시간이지만 가공값**, 체결은 15분 지연 | O(스냅샷에 `impliedVolatility`, `greeks`). **0DTE는 그릭스 없음** | 공식 + 포럼 | 분당 200회. 직원 설명: 실제 OPRA 호가가 아닌 파생값이라 실매매 판단용은 아님 |

### Alpaca 세부
- 엔드포인트: 옵션 체인 스냅샷 `GET /v1beta1/options/snapshots/{underlying}`, 계약별 `GET /v1beta1/options/snapshots`. `feed=indicative`(무료 기본) / `opra`(유료).
- 그릭스 계산 조건(공식 FAQ): 최신 호가의 bid·ask가 0이 아님, 기초자산 SIP 체결 존재, 만기가 오늘 이후, IV 계산 성공. → **0DTE와 깊은 OTM은 IV·그릭스가 비어 올 수 있다. 우리 블랙-숄즈 역산으로 채운다.**
- 무료 플랜은 옵션 과거 데이터의 최근 15분을 조회할 수 없다.
- 관련 문서: https://docs.alpaca.markets/us/reference/optionchain , https://docs.alpaca.markets/us/reference/optionsnapshots , https://docs.alpaca.markets/us/docs/market-data-faq , https://docs.alpaca.markets/us/docs/about-market-data-api , https://forum.alpaca.markets/t/what-is-the-indicative-pricing-feed-for-options/14595

### Tastytrade 세부
- REST 시세는 입금된 계좌 보유자에게 실시간으로 준다. 스트리밍은 REST에서 받은 토큰(24시간 유효)으로 DXLink 웹소켓에 접속하고, 30초마다 keepalive를 보낸다.
- 국제 계좌는 "일부 국가"만 받는다. 한국 포함 여부는 tastytrade 고객센터에 직접 확인해야 한다.
- 관련 문서: https://developer.tastytrade.com/streaming-market-data , https://tastytrade.com/learn/accounts/account-types/international-account/

### IBKR 세부 (GPT 2차 답변, 2026-11-20, 공식 문서 대조 전)
- 한국 거주자는 IBKR Pro만 개설 가능(Lite는 미국·인도 전용). 시세 구독·유지에 계좌 순자산 $500 이상 필요.
- 옵션: OPRA L1 실시간 월 $1.50(그달 IBKR 수수료 $20 이상이면 면제).
- 주식: Cboe One + IEX 비통합 실시간 시세는 무료. 통합 NBBO가 필요하면 Network A·B·C 각 $1.50(합 $4.50).
- API: TWS API, Client Portal Web API 모두 실시간 옵션 호가와 IV·그릭스 제공. 둘 다 PC에서 TWS/IB Gateway(또는 Client Portal Gateway)를 켜고 로그인해야 함. 매일 자동 재시작은 가능하지만 매주 월요일 2FA 수동 재로그인 필요.

### 기획 기능별 IBKR $1.50 커버 여부 (2026-11-20, IBKR 공식 문서 확인)

|---|---|---|---|

| 현재가, 오늘 시가 | 주식 실시간 | O (무료 Cboe One + IEX) | NBBO가 아닌 일부 거래소 시세. API에서도 사용 가능 |
| IV·그릭스(API값) | 옵션 계산값 | O | 옵션과 기초자산 시세 구독이 **둘 다** 필요 → 위 두 개로 충족 |
| IV 퍼센타일 | 과거 IV | O (예상) | 주식 대상 `OPTION_IMPLIED_VOLATILITY` 과거 봉 제공. 스냅샷을 쌓지 않아도 바로 계산 가능. 과거 데이터는 "실시간 구독이 있어야" 조회 가능하다고 되어 있어, 무료 Cboe One 구독으로 충분한지 실측 필요 |
| IV/HV | 과거 실현변동성 | O (예상) | 틱 104(30일 HV) 또는 `HISTORICAL_VOLATILITY` 봉. 위와 같은 실측 필요 |

| 실적발표일 | 실적 캘린더 | **X** | IBKR은 Wall Street Horizon 구독(소매 월 $49 수준) 필요 → 무료 Alpha Vantage `EARNINGS_CALENDAR`(하루 25회)로 대체 |
| 다른 반도체 종목 요약 | 여러 종목 시세 | 부분 | 100줄 한도 때문에 선택한 종목만 실시간, 나머지는 주기적으로 짧게 구독 |

결론: 실시간 판단 기능(체인, 스트래들, 예상 변동폭, IV)은 $1.50로 된다. **실적발표일만 IBKR로 안 되고 무료 소스(Alpha Vantage)를 같이 써야 한다.** 과거 IV·일봉이 무료 주식 시세 구독으로 조회되는지는 계좌 개설 후 실측한다.

## 1-1. 프리마켓 주가 (GPT 답변, 2026-11-24, 실측 전)
개장 예상가 기능용. 상승률은 API 필드가 아니라 `최신 체결가 ÷ 전일 종가 − 1`로 계산한다.

| 소스 | 04:00–08:00 ET | 08:00–09:30 ET | 전일 종가 필드 | 비고 |
|---|---|---|---|---|
| Alpaca Basic `GET /v2/stocks/{symbol}/snapshot?feed=iex` | **반영 안 됨** | IEX 체결이 있으면 `latestTrade`에 실시간 반영 | `prevDailyBar.c` | IEX 한 거래소 데이터라 체결이 드문드문할 수 있음 |
| IBKR `reqMktData`(무료 Cboe One + IEX) | **체결가 없음** | 해당 거래소 체결이 있으면 `last` | `tickPrice` CLOSE(tick type 9, 분할·배당 조정) | `outsideRth`는 `reqMktData` 인자가 아님. 추가 구독 불필요 |

- 결론: 두 소스 모두 **개장 직전 1시간 30분(08:00–09:30 ET, 한국시간 22:00–23:30 / 서머타임 21:00–22:30)만** 프리마켓 가격을 자동으로 받을 수 있다. 그 전 시간대이거나 체결이 오래됐으면 토스 값을 직접 입력한다.
- 자동 조회 값은 기존 `StockQuote.price`(최신 체결가)와 `previousClose`를 그대로 쓴다. 체결 시각(`asOf`)을 화면에 같이 보여 줘서 오래된 값인지 판단하게 한다.
- 관련 문서: https://docs.alpaca.markets/us/reference/stocksnapshotsingle , https://www.iex.io/resources/trading/trading-hours-holidays , https://portal.interactivebrokers.com/en/pricing/market-data-pricing.php?menu=B , https://www.cboe.com/about/hours/ , https://interactivebrokers.github.io/tws-api/tick_types.html

## 결론(사용자 결정 대기)
- **무료이면서 "진짜" 실시간 옵션 호가를 확실히 주는 곳은 확인되지 않았다.**
- 가장 현실적인 안: **Alpaca indicative(무료, 호가 실시간이지만 가공값)** 로 IV·예상 변동폭·전략 판단을 하고, 실제 체결 가격은 토스 화면으로 본다. 화면에 "가공 호가" 표시 필수.
- 업그레이드 후보: Tastytrade(한국 거주자 계좌가 되면 무료 실시간 가능성).

## 5. 실시간 푸시(WebSocket/구독) 비교 (2026-11-25, 공식 문서, 실측 전)
현재는 10초 폴링 + REST다. 감시 종목을 3~5개로 줄이고 푸시로 바꿀 수 있는지 비교한다(서버→브라우저 전달은 별도 주제). Alpaca 상세는 명세 1-5, IBKR은 명세 3-10-1.

| 항목 | Alpaca 무료(Basic) | IBKR (TWS API) |
|---|---|---|
| 주식 푸시 | O. IEX 스트림, **30 심볼** (공식) | O. `reqMktData` 구독형, 무료 Cboe One + IEX (공식) |
| 옵션 푸시 | O. `indicative`(가공 호가), **200 quotes**, msgpack만 (공식) | O. 구독형, OPRA $1.50 필요 (공식) |
| 한도 | 주식 30 심볼 / 옵션 200 quotes / 연결 1개 가정 | 동시 100줄(계약 1개=1줄), 추가는 100줄당 월 $30 |
| 종목당 필요량 | 주식 1 + 옵션 약 20~42 | 주식 1 + 옵션 약 42 ≈ 43줄 |
| 3~5종목 | 주식 5심볼은 문제없음. 옵션은 종목당 40개면 5종목 200개로 한도 딱 맞음, ATM ±10칸(42개)이면 4종목(168개)까지, 5종목은 ±8칸 이하로 | 100줄 한도로 2종목까지 ±10칸, 4종목은 ±5칸(92줄), 5종목은 더 줄이거나 줄 추가 |
| 호가 성격 | indicative = 가공값(실제 호가 아님) | OPRA 실제 호가 |
| 추가 조건 | 키만 있으면 됨. msgpack 파싱 필요 | PC에서 IB Gateway 로그인, 월요일 2FA, 순자산 $500 이상 |

결론: **Alpaca 무료로 주식·옵션 모두 구독형 푸시가 가능**하다(주식 IEX 30심볼, 옵션 indicative 200개). 3~5종목이면 한도 안에 들어오되 옵션은 종목당 약 40개(ATM ±10칸 안팎)로 제한해야 한다. 옵션 호가가 가공값이라는 한계는 그대로다. 무료 연결 수(1개 가정)와 한도 계산 방식은 실측으로 확인한다. IBKR은 실제 호가를 주지만 100줄이라 종목당 옵션 칸 수를 더 줄여야 하고 PC·계정 조건이 붙는다.
